## Open questions

- **Setup metrics.** The requirements spec suggests an opt-in anonymous setup count. That would end "Data Not Collected". These documents assume no such count in 1.0. If it is added, update the privacy label, `privacy-policy.md` and the description first.
- **Free or Pro.** The brief doesn't say which tier gets Shortcuts search actions, Face ID lock, detected codes and links, and filters. The listing treats them as free because only snooze, longer retention, unlimited apps, the widget, the Control Center toggle and stats are marked Pro. Confirm against the build.
- **README tagline.** `README.md` mentions per-app alert sounds, which are not in 1.0. Don't reuse that line in store copy or marketing.
